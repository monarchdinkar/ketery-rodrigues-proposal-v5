# Kétery Rodrigues Proposal Website V5

V5 is a portrait-first, iPhone/Safari-optimized release of the cinematic proposal site.

Files:
- `index.html`
- `Proposal.mp3`

## GitHub Pages
Upload the files to the repository root, then enable GitHub Pages from `Settings -> Pages -> Deploy from a branch -> main -> / (root)`.

## V5 improvements
- Portrait-first layout for iPhone Safari
- iOS safe-area handling
- VisualViewport sizing for dynamic browser chrome
- Scene-specific positioning to prevent overlaps
- Smaller, adaptive typography and spacing
- Reduced particle/animation load on phones
- Decorative characters/animals stay in edge lanes
- Swipe navigation only when audio is paused
- Correct per-scene backgrounds
